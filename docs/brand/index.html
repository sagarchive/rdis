rdis

An r, set in bytes.

A binary is a grid of bytes. rdis finds the structure inside it. The mark is a lowercase r built from five byte cells, and the amber cell is the byte you have selected.

The idea

From bytes to structure.

The mark tells the product's story in three steps, on the same 3 × 3 grid.

01 · Bytes

A file is just cells.

Nine identical bytes. No meaning yet, exactly what a binary looks like before analysis.

02 · Structure

Analysis lights a shape.

Five cells connect into a stem and a branch. That's a lowercase r, and also the outline of a control-flow edge.

03 · Selection

One byte in focus.

The empty cells drop away. The branch ends in amber, the same highlight the app uses for the line under your cursor.

Construction

Built on one module.

Every measurement comes from the byte cell.

1 module
16.5 units, one byte cell on a 96-unit canvas.
Gutter
¼ module between cells, so the shape reads as one letter.
Cell radius
3.5 units, which keeps each cell a byte, not a dot.
Margin
19 units on every side. The glyph is centered on a 3 × 3 grid.
Container
22.2% corner radius, matching macOS and iOS app icons.
Favicon
A separate optical cut with 18-unit cells and flat amber, so it stays crisp at 16 px.

Lockup

Icon and name.

The wordmark is San Francisco Semibold, tracked −3.5%. Leave at least one module of clear space around it.
